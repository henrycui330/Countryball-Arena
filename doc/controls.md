# Countryball PVP — Controls

Open `code/index.html` in a browser.

## Main menu
1. **Title screen** — Countryball PVP; choose **Quick Match** or **Custom Match**
2. **Setup** — fighter, opponent, map (**Plains** / **Icy**), (custom only) equal lives → **Fight!**
3. **Back** returns to the title screen

## Arena
| Input | Action |
|--------|--------|
| **W A S D** (or arrows) | Move |
| **LMB** (click) | Normal attack |
| **LMB hold → release** | Charged attack |
| **E** | Special |
| **Q** | Ultimate (needs full ult charge) |
| **Esc** / **Menu** | Leave to main menu |

### USA
- LMB: Deagle bash · Hold: spin then shoot · E: 5 money stacks · Q: Eagle star drop

### Japan
- LMB: Katana strike · Hold: shove across arena then abdomen stab · E: 3 guided shuriken · Q: white/black cinema lightning stab

### Russia
- LMB: Absolut bottle bash · Hold: stun barrage (foe can't move/attack) · E: drink — heal + speed · Q: summon Kazakhstan, Belarus, Ukraine (slam then fight 30s)

## Lives (Custom)
- Both sides always start with the **same** life count (1–100).
- Losing a stock = KO explosion + respawn; at 0 lives → Victory / Defeat screen.

## Enemy bots
- Shoot + **one melee weapon** each (no charged, no ult).
- Easy: Absolut · Medium: Deagle · Hard: Katana

## Camera
- Distance zoom; ult / KO focus; finisher slo-mo only if one hit can KO.
